Vantage package repositories

Signed package repositories for Vantage, a LuCI theme and dashboard for OpenWrt 25.12 and 24.10.

OpenWrt 25.12 (apk)

One-time setup on the router, then install and upgrade with apk:

wget -O /etc/apk/keys/vantage-signing.pem https://anothadev.github.io/luci-theme-vantage/vantage-signing.pem
sha256sum /etc/apk/keys/vantage-signing.pem
# must print c8a6c83eeb49ca2407932fb5e95785776128cef87db75ebaea0fe4171eee2157
echo 'https://anothadev.github.io/luci-theme-vantage/25.12/packages.adb' >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add luci-theme-vantage luci-app-vantage

Translations, where available, are separate packages: apk add luci-i18n-vantage-<lang> luci-i18n-vantage-theme-<lang> (for example zh-cn); choose the language under System → System → Language and Style.

OpenWrt 24.10 (opkg)

One-time setup on the router, then install and upgrade with opkg:

wget -O /tmp/vantage-24.10.usign.pub https://anothadev.github.io/luci-theme-vantage/vantage-24.10.usign.pub
usign -F -p /tmp/vantage-24.10.usign.pub
# must print 297430484082d03d
opkg-key add /tmp/vantage-24.10.usign.pub
echo 'src/gz vantage https://anothadev.github.io/luci-theme-vantage/24.10' >> /etc/opkg/customfeeds.conf
opkg update
opkg install luci-theme-vantage luci-app-vantage

Translations: opkg install luci-i18n-vantage-<lang> (for example zh-cn).

What changed in each release: CHANGELOG.md; the packages are also attached to the releases.

Compare the key fingerprints with the ones in the project's install guide before trusting it.
